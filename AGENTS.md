# catalogos — public metadata authority

This repository catalogs PUBLIC, NON-SECRET references and their evidence states.
It does not own implementation, device truth, corpus contents, PATs or private receipts.
Producer authority stays with the source repository; scientific interpretation belongs in conhecimentos.
All changes enter draft PRs and run read-only CI with no secret dependencies.
A user report is not a device proof; source presence is not an execution receipt.
Never include usernames, email, device IDs, local paths, private repository identifiers,
auth headers, bearer strings, tokens, raw screenshots, logs or full private manifests.
No auto-promotion, auto-merge, or remote write from public CI.
SOURCE != ARTIFACT != EXECUTION != EVIDENCE != CLAIM.
TOKEN_VAZIO != 0; claim_allowed=false unless a separately authorized evidence gate exists.
Corrections are additive successor records; no destructive rewriting of prior evidence.
